# Matrix Client

Этот каталог содержит только Electron/Vue-клиент Matrix. Серверный gRPC/Manticore-проект
развертывается отдельно. Клиент не подключается к MariaDB напрямую и не хранит
локальную копию базы.

## Запуск

```bash
npm install
npm run dev
```

Для подключения к серверу используйте сборку со встроенным CA-сертификатом.
В разделе «Настройки» укажите адрес сервера в формате `host:port` и API-ключ.
Начальный адрес `localhost:50051` подходит для сервера на том же компьютере. Для
подключения по сети укажите IP-адрес или DNS-имя, подтверждённое сертификатом сервера.
Matrix использует только встроенный CA-сертификат. Чтобы сменить доверенный CA,
соберите новую версию приложения.

Если администратор выдал персональный ключ устройства, введите его в поле
«API-ключ». При первом подключении сервер свяжет ключ с профилем Windows на этом
компьютере. Для другого компьютера администратор выдаёт новый ключ.

Поиск поддерживает поля `number`, `mail`, `snils`, `inn`, `passport`, `fio`,
`date_of_birth`, `telegram`, `vk`, `facebook`, `imei`, `imsi`, `grz` и `vin`.
Обычные значения передаются без преобразования. `%` и `?` работают как маски только при
явном вводе пользователем.

Manticore отдает все совпадения через Scroll, а gRPC передает их клиенту потоком. Параметр
«Размер страницы потока» управляет одной страницей и не ограничивает общее число результатов.
Длинный поиск можно остановить кнопкой в активной вкладке.

## Сборка

Для сборки укажите файл с одним публичным CA-сертификатом сервера в формате PEM.

```bash
npm run build:portable -- /path/to/server-ca.crt
npm run build:win -- /path/to/server-ca.crt
npm run build:linux -- /path/to/server-ca.crt
```

## Проверки

После клонирования выполните `npm run hooks:install`, чтобы включить проверки
перед коммитом и отправкой. Режимы проверки и ограничения описаны в
[правилах публикации](docs/publication.md).

```bash
npm test
npm run build:client
node scripts/checkPublication.mjs
```

Проверка публикации рассматривает текущие отслеживаемые и неигнорируемые файлы,
сообщает только пути, номера строк и виды находок. Локальные сертификаты, ключи,
данные, сборки и рабочие планы остаются вне Git.

История репозитория начинается с чистого снимка исходников без прежних сведений об
окружении. Публиковать можно непосредственно этот репозиторий; отдельный экспорт
исходников не требуется. Перед публикацией выполните проверки выше и убедитесь,
что адрес Git remote соответствует нужному репозиторию.

Если удалённая ветка уже содержит прежнюю историю, её замена требует отдельного
согласованного обновления удалённого репозитория. Локальная очистка сама по себе
не изменяет GitHub и другие существующие копии.

Проверка подключения к вашему серверу требует явных настроек:

```bash
MATRIX_API_KEY=your-api-key MATRIX_CA_CERT_PATH=/path/to/trusted-ca.crt npm run client:check -- --endpoint localhost:50051 --field number --value test-value
```
